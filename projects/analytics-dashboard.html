Webanly

A self-hosted web analytics platform I designed and built from the ground up — event pipeline, live dashboards, and everything in between. Visitors land on a tracked site, and the data is on screen before they've finished loading the next page.

The challenge

Most analytics tools are black boxes — you drop in a script and trust a third party with your data. I wanted to build the alternative: a platform where I owned every piece of the pipeline, from the tracking script on the client's page to the pixel on the dashboard chart, and where "real-time" actually meant real-time, not a five-minute refresh.

What I built

  • A lightweight, cookie-free tracking script and a full event pipeline — collector → Kafka → Postgres — handling everything from pageviews to exit intent.
  • A dual-topic Kafka design that separates durable event storage from a slim real-time stream, so the live dashboard and historical reports never compete for the same data path.
  • A WebSocket layer that merges live traffic straight into the same charts the REST API populates, with zero visual seams between "historical" and "happening now."
  • Redis-backed spike detection with a self-adjusting baseline — the platform learns what "normal" traffic looks like for each site and alerts you the moment it's not.
  • Timezone-correct reporting down to the SQL query level, so "today" means today for the visitor, not for the server.
  • A fully containerized deployment — multi-stage Docker builds, Turborepo-pruned images, and a Compose stack that brings up Postgres, Redis, Kafka, and both apps with one command.

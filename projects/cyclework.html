Workcycle

A goal-tracking and productivity dashboard that helps people plan their goals in time-boxed cycles, break them into daily tasks, and see their execution progress automatically.

RoleFull Stack Developer
MethodTime-boxed cycles
FocusExecution tracking

The challenge

Big goals are easy to set and easy to lose track of. Workcycle gives every goal a clear cycle with a start and end date, then breaks it down into daily tasks — so progress stays visible instead of getting buried in a to-do list.

What I built

  • Google sign-in, so users can start tracking goals in one click.
  • Cycle, goal, and task management with drag-and-drop status updates.
  • An automatic daily execution score that recalculates itself every time a task is completed — no manual tracking needed.
  • Daily and weekly trend views to see progress over an entire cycle at a glance.
